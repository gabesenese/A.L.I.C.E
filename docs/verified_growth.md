# Verified Growth

Alice changes are accepted only when they satisfy:

1. Capability added
2. Behavior replaced
3. Invariant enforced
4. Evidence produced
5. Visible flow improved
6. Old code deleted/simplified when possible

Rules:

- Model-first does not mean evidence-free.
- Runtime verifies; `alice-ollama` speaks.
- Operator mode may only claim what evidence proves.
- Codebase claims require local/action evidence.
- Memory claims require memory records.
- Tool/action claims require `ActionResult`/`local_execution` evidence.
- Educational/concept mode must not leak operator scaffolding.
- Greeting mode must not become task intake.
- No fallback personality.
- No hidden magic.
